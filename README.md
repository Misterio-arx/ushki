# 🎧 Ушки

Веб-приложение для проверки слуха — четыре интерактивных теста.

**🌐 Живая версия:** в разработке (скоро)

## 🎯 Тесты

| Тест | Что проверяет | Время |
|---|---|---|
| 🎚️ **Порог слышимости** | Какие частоты вы слышите, а какие — нет | ~5 мин |
| 🎨 **Синопсия: цветной слух** | Какой цвет возникает при звуке | ~3 мин |
| 🎵 **Различение высоты тона** | Обычный и профессиональный режимы | ~5 мин |
| ⏱️ **Хроностезия** | Оценка времени на слух (2 режима) | ~7 мин |

## ✨ Возможности

- 📄 **Скачивание PDF** с результатами
- ✉️ **Отправка результатов** на email через EmailJS
- 💾 **Сохранение прогресса** в localStorage (при обновлении страницы)
- 🌙 **Тёмная и светлая темы** с автоопределением
- 📱 **Мобильная адаптация** — работает на телефоне
- 📊 **Прогресс-бары** в тестах
- 🔒 **Политика конфиденциальности** и согласие на обработку данных
- 🎯 **Научный метод** — тест высоты тона использует 2-down/1-up (Левитт, 1971)

## 🛠 Технологии

- **Backend:** Django 6.1, SQLite
- **Frontend:** HTML, CSS, JavaScript (без фреймворков)
- **Аудио:** Web Audio API (sine/triangle), MP3
- **PDF:** jsPDF + html2canvas
- **Email:** EmailJS
- **Графика:** CSS-переменные, SVG-иконки

# 🎧 Ушки

Веб-приложение для проверки слуха — четыре интерактивных теста.

## 🎯 Тесты

| Тест | Что проверяет |
|---|---|
| 🎚️ **Порог слышимости** | Какие частоты вы слышите, а какие — нет |
| 🎨 **Синопсия: цветной слух** | Какой цвет возникает при звуке |
| 🎵 **Различение высоты тона** | Обычный и профессиональный режимы |
| ⏱️ **Хроностезия** | Оценка времени на слух (2 режима) |

## ✨ Возможности

- 📄 **Скачивание PDF** с результатами
- ✉️ **Отправка результатов** на email через EmailJS
- 💾 **Сохранение прогресса** в localStorage
- 🌙 **Тёмная и светлая темы**
- 📱 **Мобильная адаптация**
- 📊 **Прогресс-бары** в тестах
- 🔒 **Политика конфиденциальности** и согласие на обработку данных

## 🛠 Технологии

- **Backend:** Django 6.1, SQLite
- **Frontend:** HTML, CSS, JavaScript
- **Аудио:** Web Audio API, MP3
- **PDF:** jsPDF + html2canvas
- **Email:** EmailJS

# 🎧 Ушки

Веб-приложение для проверки слуха — четыре интерактивных теста.

## 🎯 Тесты

| Тест | Что проверяет | Время |
|---|---|---|
| 🎚️ **Порог слышимости** | Какие частоты вы слышите, а какие — нет | ~5 мин |
| 🎨 **Синопсия: цветной слух** | Какой цвет возникает при звуке | ~3 мин |
| 🎵 **Различение высоты тона** | Обычный и профессиональный режимы | ~5 мин |
| ⏱️ **Хроностезия** | Оценка времени на слух (2 режима) | ~7 мин |

## ✨ Возможности

- 📄 **Скачивание PDF** с результатами
- ✉️ **Отправка результатов** на email через EmailJS
- 💾 **Сохранение прогресса** в localStorage (при обновлении страницы)
- 🌙 **Тёмная и светлая темы** с автоопределением
- 📱 **Мобильная адаптация** — работает на телефоне
- 📊 **Прогресс-бары** в тестах
- 🔒 **Политика конфиденциальности** и согласие на обработку данных
- 🎯 **Научный метод** — тест высоты тона использует 2-down/1-up (Левитт, 1971)

## 🛠 Технологии

- **Backend:** Django 6.1, SQLite
- **Frontend:** HTML, CSS, JavaScript (без фреймворков)
- **Аудио:** Web Audio API, MP3
- **PDF:** jsPDF + html2canvas
- **Email:** EmailJS
- **Графика:** CSS-переменные, SVG-иконки

## 🚀 Как запустить локально

### Требования

- **Python 3.10+** — [скачать](https://www.python.org/downloads/)
- **Git** — [скачать](https://git-scm.com/downloads)

### Шаги

**1. Клонируйте репозиторий:**

```bash
git clone https://github.com/Misterio-arx/ushki.git
cd ushki
```

**2. Создайте виртуальное окружение:**

```bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
```

**3. Установите зависимости:**

```bash
pip install django
```

**4. Примените миграции:**

```bash
python manage.py migrate
```

**5. Запустите сервер:**

```bash
python manage.py runserver
```

**6. Откройте в браузере:**

```
http://127.0.0.1:8000/
```

### Доступ с телефона (в той же Wi-Fi)

**1. Узнайте IP компьютера:**

```bash
# Windows
ipconfig

# macOS / Linux
ifconfig
```

Найдите **IPv4-адрес** — например, `192.168.0.105`.

**2. В `config/settings.py` разрешите хост:**

```python
ALLOWED_HOSTS = ['*']
```

**3. Запустите сервер:**

```bash
python manage.py runserver 0.0.0.0:8000
```

**4. Откройте на телефоне:**

```
http://192.168.0.105:8000
```

### Возможные проблемы

| Проблема | Решение |
|---|---|
| **`python не найден`** | Установите Python 3.10+ и добавьте в PATH |
| **`django не найден`** | Активируйте `.venv` и запустите `pip install django` |
| **Порт 8000 занят** | Запустите на другом порту: `python manage.py runserver 8001` |
| **Сайт не открывается на телефоне** | Проверьте, что телефон и ПК в одной Wi-Fi, и `runserver 0.0.0.0:8000` |
| **Звук не работает** | Разрешите автовоспроизведение в браузере, наденьте наушники |
